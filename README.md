# Enkrip

Website enkripsi ringan dan interaktif yang dibangun dengan HTML, CSS, dan JavaScript. Semua proses enkripsi dan dekripsi dilakukan langsung di browser — tanpa backend, tanpa kirim data ke server.

##  Fitur

-  **Base64** — encode/decode teks
-  **Caesar Cipher** — enkripsi sederhana dengan shift
-  **AES-256** — enkripsi kuat menggunakan kunci (CryptoJS)
-  **ROT13** — enkripsi simetris tanpa kunci
-  **Pure frontend** — semua proses lokal, aman dan cepat
-  Salin hasil dengan satu klik
